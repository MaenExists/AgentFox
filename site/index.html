The Surface. Twelve Commands.

Every operation designed for the agent loop. Zero fluff. Machine-optimized.

Command Usage Description
search afox search <q> Smart navigation. Resolves URLs or searches via DuckDuckGo.
open afox open <url> Navigate the current session to a specific URL.
view afox view [-s] Clean Markdown with stable element IDs.
snap afox snap [-s] Raw semantic JSON tree.
click afox click <id> Realistic click. Full event sequence: pointerdown to click.
fill afox fill <id> <v> Form input with proper event triggering.
text afox text <id> Clean text from any element.
eval afox eval <code> Raw JS execution in page context.
auth afox auth <key> [url] [model] Set LLM credentials for summarization.
ping afox ping Check daemon. Auto-starts if not running.
quit afox quit Shutdown the daemon cleanly.
